# 블록 쌓기

내려오는 블록을 옮기고 돌려서 가로 한 줄을 채우면 줄이 사라지는 간단한 퍼즐 게임입니다.

- `index.html`을 브라우저로 열면 바로 시작합니다. 설치·서버·인터넷이 필요 없고, 외부 라이브러리·글꼴·분석 도구도 쓰지 않습니다.
- 규칙(`game.js`)은 화면과 떨어져 있고, 자동 시험이 붙어 있습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← → | 옮기기 |
| ↑ 또는 X / Z | 시계 / 반시계 방향으로 돌리기 |
| ↓ | 천천히 내리기 (칸당 1점) |
| 스페이스 | 바로 내리기 (칸당 2점) |
| P | 일시정지 |
| Enter | 게임 끝난 뒤 다시 시작 |

화면 아래 버튼으로도 조작할 수 있습니다(휴대폰용).

## 점수

한 번에 지운 줄 수가 1·2·3·4줄이면 100·300·500·800점에 레벨을 곱합니다. 10줄을 지울 때마다 레벨이 오르고 떨어지는 속도가 빨라집니다.
