# Sambong — 설문 집계기

`index.html` 하나로 동작하는 설문 집계기입니다. 엑셀에서 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표(문항 / 유효 응답 / 평균 / 빈 응답 / 제외)가 나오고, 그 아래에 문항별 파이 차트(유효 응답 / 빈 응답 / 제외 비율)가 나옵니다.

- 외부 라이브러리·외부 글꼴·분석 도구 없음. 붙여넣은 데이터는 브라우저 밖으로 보내거나 저장하지 않습니다 (CSP로도 막음).
- 첫 열(응답번호)은 집계하지 않습니다.
- 칸 판정과 평균 규칙은 [PLAN.md](PLAN.md) 참고.

## 사용

`index.html`을 브라우저로 열거나 GitHub Pages로 게시합니다 (`.nojekyll` 포함).

## 시험

계산 로직은 화면과 분리되어 있고(`index.html`의 `tally-core` 스크립트), Node만으로 시험합니다.

```bash
npm test
```
